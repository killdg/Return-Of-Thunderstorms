# Return Of Thunderstorms 1.2.1 — solo test build

Created by killdg with assistance from ChatGPT.

Standalone rain/thunder/lightning weather, optional hurricane gusts and night-only debris, native eye/goggle rain enhancement, night lightning-driven map-light flicker, and four saved sound-balance sliders. Targets SPT 4.1.6 / EFT 0.16.9.40743. No Raid Roulette dependency.

Install instructions are in START-HERE.txt inside the ZIP and the repository README. Copy both folders from INSTALL into the SPT root with the game, launcher and server closed.

For ordinary weather with occasional thunderstorms, use 25–50% storm chance and 0% rain boost. For a quick test, set both to 100% before an outdoor raid, then restore rain boost afterward. Night debris and light flicker run between 20:00 and 06:00.

Testing used a clean SPT/Tarkov baseline. Other mod combinations are not guaranteed. Fika testing is planned; synchronization is not implemented and this release is not Fika-supported. Loading pauses remain under investigation and have not been isolated to this mod. Treat this as a test build.

Client 1.2.1; server 1.2.0-preview.2. Source and supplied recordings are included in the repository. No profiles, saved personal configurations or proprietary game binaries are included.
