# Return Of Thunderstorms 1.2.2

Packaging correction for the SPT mod page. No gameplay changes from client 1.2.1. Client and server metadata now identify this package as 1.2.2.

The ZIP root contains exactly:

- README.md
- BepInEx/
- SPT_Runtime/

There is no INSTALL wrapper, START-HERE file, checksum manifest, or extra top-level directory. Extract the ZIP and copy both folders into your SPT root with the game, launcher and server closed. All four rain/thunder WAV recordings are included. No profiles or saved personal settings are included.

Created by killdg, with assistance from ChatGPT. Full features, F1 settings, instructions and the MIT license notice are in README.md.

Testing and compatibility limits remain unchanged: development used a clean SPT/Tarkov baseline; other-mod compatibility is unverified; Fika support is planned but not established. Loading pauses remain under investigation and are not claimed to be fixed. Targets SPT 4.1.6 / EFT 0.16.9.40743.
